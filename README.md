useless-superpower is a tiny program that writes one line about a hilariously useless superpower to a file: invisibility that only works when the bearer is already alone in a room with the lights off.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.

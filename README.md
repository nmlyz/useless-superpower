A small Python program that writes a single line about a superpower that is no help at all: invisibility that only switches on when nobody is there to see it — alone in a room, with the lights off.

## The line

> I can turn invisible, but only when I'm already alone in a room with the lights off.

The line is assembled from two clauses, one for the power and one for the conditions that cancel it, and each clause is checked before the file is written.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Standard library only, no network, and the output is identical byte for byte on every run.
